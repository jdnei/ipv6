# 🌐 آموزش فعال‌سازی و آزمایش IPv6(به‌روزرسانی 13 نوامبر 2026)
> محدودیت‌های اینترنت در سرزمین اصلی چین روزبه‌روز شدیدتر می‌شوند و بسیاری از سرورهای VPN دیگر قابل استفاده نیستند. فعال‌سازی IPv6 به‌عنوان یک راهکار احتمالی به‌شدت توصیه می‌شود. یادگیری این مهارت برای همه کاربران VPN ضروری است.<br>

## روش فعال‌سازی IPv6

### مرحله ۱: بررسی پشتیبانی شبکه محلی از IPv6

1. **اتصال VPN یا پروکسی را قطع کنید**

   تمام برنامه‌های پروکسی را ببندید و تنظیمات پروکسی سراسری سیستم را غیرفعال کنید.

2. به وب‌سایت زیر مراجعه کنید:

   <https://ipleak.net/>

3. نتایج آزمایش را بررسی کنید:

   - ✅ اگر دو آدرس IP مشاهده کردید و یکی از آن‌ها شبیه نمونه زیر بود:

     ```text
     2a05:d014:1f70:b000:c129:d6be:c347:abcd
     ```

     این آدرس طولانی نشان می‌دهد که شبکه محلی شما از IPv6 پشتیبانی می‌کند. می‌توانید به مرحله بعد بروید.

   - ❌ اگر پیام زیر نمایش داده شد:

     ```text
     IPv6 test not reachable. (error)
     ```

     یعنی IPv6 در حال حاضر در شبکه محلی شما در دسترس نیست و این روش کار نخواهد کرد. ابتدا پشتیبانی IPv6 توسط ارائه‌دهنده اینترنت یا تنظیمات IPv6 روتر خود را بررسی کنید.

---

### مرحله ۲: فعال‌سازی IPv6 در برنامه VPN یا پروکسی

1. برنامه VPN یا پروکسی خود را باز کنید.
2. گزینه **فعال‌سازی IPv6 ورودی** را پیدا کرده و روشن کنید. برای یافتن محل دقیق این گزینه، به فهرست برنامه‌های رایج در ادامه مراجعه کنید.
3. **برنامه را کاملاً ببندید و سپس دوباره اجرا کنید.**

---

### مرحله ۳: بررسی فعال‌شدن موفق IPv6

1. VPN یا پروکسی را فعال کنید و دوباره به وب‌سایت زیر بروید:

   <https://ipleak.net/>

2. اگر نتیجه‌ای شبیه نمونه زیر مشاهده کردید:

   ```text
   آدرس IPv6:
   2a05:d014:1f70:b000:c129:d6be:c347:abcd

   موقعیت خارج از سرزمین اصلی چین، برای مثال:
   Amazon.com, Inc
   ```

   ✅ این نتیجه نشان می‌دهد که IPv6 با موفقیت فعال شده است.

## محل فعال‌سازی IPv6 در برنامه‌های محبوب VPN

### 📱 Android

| برنامه | مسیر تنظیمات |
| --- | --- |
| **Bettbox** | بیشتر → پیکربندی هسته → عمومی → IPv6 |
| **Flclash** | ابزارها → پیکربندی پایه → IPv6 |
| **Flyclash** | ① تنظیمات → شبکه → اجازه استفاده از IPv6　② تنظیمات → بازنویسی تنظیمات → عمومی → IPv6 فعال است |
| **Clash Meta** | ① تنظیمات → شبکه → اجازه استفاده از IPv6　② تنظیمات → بازنویسی تنظیمات → عمومی → IPv6 فعال است |
| **Nekobox** | تنظیمات → تنظیمات مسیریابی → اولویت مسیریابی IPv6 |
| **V2rayNG** | تنظیمات → تنظیمات VPN → فعال‌سازی IPv6 + اولویت IPv6 |
| **Clashmi** | تنظیمات هسته → فعال‌سازی IPv6 |
| **Karing** | نماد چرخ‌دنده بالا سمت چپ → فعال‌سازی IPv6 / اولویت IPv6 |
