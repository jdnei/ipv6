# 🌐 IPv6 的开启和检测方法

> 最后更新：(2026年09月07日)

## IPv6 开启方案

### 第一步：检测本地 IPv6 是否可用

1. **断开代理**  
   关闭所有代理软件或系统代理设置。

2. 访问：

   <https://ipleak.net/>

3. 查看检测结果：

   - ✅ 如果看到两条 IP 地址，其中一条类似：

     ```text
     2a05:d014:1f70:b000:c129:d6be:c347:abcd
     ```

     这样的长地址，说明本地已经有 IPv6，可以继续下一步。

   - ❌ 如果显示：

     ```text
     IPv6 test not reachable. (error)
     ```

     说明本地没有可用 IPv6，本方案无效。请先检查运营商或路由器的 IPv6 设置。

---

### 第二步：在代理软件中开启 IPv6

1. 打开你的代理软件。
2. 找到 **IPv6 入站开关** 并开启，具体位置可参考下方常用软件列表。
3. **彻底关闭代理软件，然后重新打开。**

---

### 第三步：验证 IPv6 是否成功启用

1. 开启代理，再次访问：

   <https://ipleak.net/>

2. 如果看到类似：

   ```text
   IPv6 地址：
   2a05:d014:1f70:b000:c129:d6be:c347:abcd

   归属地是海外，例如：
   Amazon.com, Inc
   ```

   ✅ 即说明 IPv6 已成功开启。

## 常用代理软件 IPv6 开启位置

### 📱 Android

| 软件名称 | 设置路径 |
| --- | --- |
| **Bettbox** | 更多 → 内核配置 → 常规 → IPv6 |
| **Flclash** | 工具 → 基本配置 → IPv6 |
| **Flyclash** | ① 设置 → 网络 → 允许 IPv6　② 设置 → 覆写 → 常规 → IPv6 已启用 |
| **Clash Meta** | ① 设置 → 网络 → 允许 IPv6　② 设置 → 覆写 → 常规 → IPv6 已启用 |
| **Nekobox** | 设置 → 路由设置 → IPv6 路由优先 |
| **V2rayNG** | 设置 → VPN 设置 → 启用 IPv6 + IPv6 优先 |
| **Clashmi** | 核心设置 → IPv6 启用 |
| **Karing** | 左上角齿轮 → IPv6 启用 / 优先 |

---

### 🍎 iOS

| 软件名称 | 设置路径 |
| --- | --- |
| **Shadowrocket** | 配置 → 本地文件 ⓘ → 启用 IPv6 + IPv6 优先 |
| **Loon** | 配置 → 高级配置 → IP stack → IPv6 优先，同时开启 TUN IPv6 配置 |
| **Karing** | 左上角齿轮 → IPv6 启用 / 优先 |
| **Clashmi** | 核心设置 → IPv6 启用 |

---

### 🖥 Windows

| 软件名称 | 设置路径 |
| --- | --- |
| **V2rayN** | 设置 → 参数设置 → TUN 模式设置 → 启用 IPv6（使用时需要使用 TUN 模式） |
| **Clash Verge** | 设置 → IPv6 打开 |
| **Bettbox** | 更多 → 内核配置 → 常规 → IPv6 |
| **Flclash** | 工具 → 基本配置 → IPv6 |
| **Clash Party / Sparkle** | 左侧内核设置 → IPv6 启用 |
| **Clashmi** | 核心设置 → IPv6 启用 |
| **Karing** | 左上角齿轮 → IPv6 启用 / 优先 |

> [!TIP]
> 如果以上软件名称或设置路径与你当前版本不完全一致，请在软件设置界面中寻找类似 **“IPv6”**、**“v6”**、**“入站”** 等关键词。
