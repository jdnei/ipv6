# 🌐 Как включить и проверить IPv6 (обновлено 3 ноября 2026)

> Интернет-ограничения в материковом Китае становятся всё строже, и многие VPN-серверы перестают работать. Настоятельно рекомендуется включить IPv6 в качестве возможного решения этой проблемы. Это важный навык, который стоит освоить каждому пользователю VPN.<br>

## Инструкция по включению IPv6

### Шаг 1. Проверьте доступность IPv6 в локальной сети

1. **Отключите VPN или прокси**

   Полностью закройте все прокси-приложения и отключите системные настройки прокси.

2. Откройте сайт:

   <https://ipleak.net/>

3. Проверьте результаты:

   - ✅ Если отображаются два IP-адреса и один из них похож на следующий:

     ```text
     2a05:d014:1f70:b000:c129:d6be:c347:abcd
     ```

     Такой длинный адрес означает, что ваша локальная сеть уже поддерживает IPv6. Можно переходить к следующему шагу.

   - ❌ Если отображается сообщение:

     ```text
     IPv6 test not reachable. (error)
     ```

     Это означает, что IPv6 в вашей локальной сети сейчас недоступен, поэтому данный способ не сработает. Сначала проверьте поддержку IPv6 у интернет-провайдера или настройки IPv6 на маршрутизаторе.

---

### Шаг 2. Включите IPv6 в VPN- или прокси-приложении

1. Откройте своё VPN- или прокси-приложение.
2. Найдите и включите **переключатель входящего IPv6**. Расположение этой настройки для популярных приложений указано ниже.
3. **Полностью закройте приложение, затем запустите его заново.**

---

### Шаг 3. Проверьте успешное включение IPv6

1. Включите VPN или прокси и снова откройте:

   <https://ipleak.net/>

2. Если результат выглядит примерно следующим образом:

   ```text
   IPv6-адрес:
   2a05:d014:1f70:b000:c129:d6be:c347:abcd

   Местоположение за пределами материкового Китая, например:
   Amazon.com, Inc
   ```

   ✅ Это означает, что IPv6 успешно включён.

## Где включить IPv6 в популярных VPN-приложениях

### 📱 Android

| Приложение | Путь к настройке |
| --- | --- |
| **Bettbox** | Дополнительно → Конфигурация ядра → Общие → IPv6 |
| **Flclash** | Инструменты → Базовая конфигурация → IPv6 |
| **Flyclash** | ① Настройки → Сеть → Разрешить IPv6　② Настройки → Переопределения → Общие → IPv6 включён |
| **Clash Meta** | ① Настройки → Сеть → Разрешить IPv6　② Настройки → Переопределения → Общие → IPv6 включён |
| **Nekobox** | Настройки → Настройки маршрутизации → Приоритет маршрутизации IPv6 |
| **V2rayNG** | Настройки → Настройки VPN → Включить IPv6 + Предпочитать IPv6 |
| **Clashmi** | Настройки ядра → Включить IPv6 |
| **Karing** | Значок шестерёнки в левом верхнем углу → Включить IPv6 / Предпочитать IPv6 |
